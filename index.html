关于此页面

这个页面展示了 HTML5 和 CSS3 的基础布局能力。HTML 负责构建页面的骨架（语义化标签），而 CSS 负责美化页面的外观（颜色、间距、字体等）。

你可以尝试修改这里的文字，或者更改 style 标签中的颜色，来体验网页开发的乐趣。
